The retained model and restoration objective match the paper. Treating additional PPR access as the next necessary completion step does not. Pause that access work as an optional development extension. No further browser/download task is required from the user for the main study. This supersedes the recent recommendation to make an interactive Baidu check the next project dependency; it does not erase the access findings or frozen batch.

The study concerns photographic restoration, not physical skin-colour recovery. Exactly lighting-invariant MST, perfect segmentation, new capture equipment and additional datasets are not universal completion prerequisites. Decisions belong to the researchers; no adviser approval is imposed.

## What the latest result actually changes

Bounded search reduced summed fitting control SSE from 2.55610013 to 0.41827826, about 83.6%, without reliable held-photo correction. Held cool RGB error rose from input 2.1413 to output 18.5255; all 11 held original references changed. One fold had zero fitting loss while applying the same darkening controls to all four held roles. This supports a transfer problem in the tested feature/target/tree setup, not a numerical inverse bug or proof that every decision tree must fail.

The 11-photo diagnostic is small and incomplete: blue targets are constant, strengths are fixed and there are no combined conditions. The older 82-source programme already tested broader conditions and failed. Consequently neither simply adding recipe names nor simply acquiring 16 editor pairs has an established repair rationale. Existing tests remain closed; no deeper tree, altered loss, extra gate, feature sweep or new annotation cycle follows from this review.

## Recommended next deliverable

Before any more acquisition or fit, perform one training-evidence feasibility assessment using existing exposed development feature/control records only. Its concrete output must distinguish whether incompatible correction targets occur at exactly identical observable feature vectors, versus at distinguishable vectors that the tested trees nevertheless grouped together. Examine correction-control variation within and across the existing known source groups, distinguish repeated variants from independent sources, and report whether ITA/MST varies independently enough to support the intended conditioning claim. Exact conflicts are evidence about deterministic identifiability on those records; absence of conflicts does not prove learnability or transfer. Do not turn distances or descriptive overlap into a new runtime threshold, identity classifier or feature-selection sweep.

At the same time, map those existing records to the primary paper task: actual implemented distortion order/units versus Table 2, three-output target reachability, eligible source/group allocation and MST strata. Use existing target audits and historical broad-coverage results; do not regenerate those experiments. The deliverable is a single go/no-go feasibility brief identifying a specific new testable correction hypothesis, or stating that none is supported under the current constraints. It must not quietly authorize another fit. A future intervention requires a prospective primary-task protocol and a genuinely different reason it should address the observed direction/identity failures.

Stop after that brief if no distinct supported intervention exists. Explain the concrete constraint to the user and present the decision it creates, rather than repeating source checks, producing more annotation queues or promising a finished model from more data. Keep the user's working-model objective active; a negative-results paper is not substituted by default.

## Completion path after a supported intervention

1. Establish primary-task feature/target feasibility and a specific correction-learning hypothesis from exposed data.
2. Freeze one justified development comparison against uncorrected inputs, with task-matched metrics, grouping, harms and stop rules. Preserve all previous failures and their original gates. Exact unchanged-output preservation was an engineering criterion of particular trials, not a verbatim universal paper requirement; failing colour restoration already matters independently.
3. Only if supported by results, prepare full declared task coverage and one compatible measurement/MST/features/tree/rendering contract. Define unresolved Table 2 slider interpretation, MST-E allocation contradiction and disparity formula explicitly before the corresponding experiment; do not invent labels or retrospectively reinterpret results.
4. Freeze a qualifying candidate before separately authorized independent evaluation, real expert MOS and Android integration/parity. Final24 and older locked image bytes remain unread throughout present development.

PPR remains a possible optional paired-editor extension if its distinct value and access are later established. It is neither abandoned evidence nor the critical path by default. No claim that the current correction model is finished or that completion is guaranteed.
