# Labelled manual measurement preparation protocol — 10 November 2026

Prepare an isolated annotation queue from all 30 existing native development
records / ten publisher subjects. This is new human-assisted data preparation,
not a repeat of scripts713–718 or a correction experiment. No original source
photo, later/final image, model inference, calibration or fit is permitted here.

Before copying cached images, verify them against the historical artifact hash
inventory and bind the saved results, plan and verification. Retain original
source hashes, decimal MST labels, publisher groups, condition, automatic status
and failure reason. Hide reference scores while painting. A score is inherited
publisher evidence, not an annotator estimate or a proven photographic target.

Each task uses the exact cached native-context normalized input. This gets a
separate method identity from the whole-image desktop square workflow. It must
not reuse old calibration coefficients or be pooled with desktop measurements
by claiming that their Lab formula is the same. Native crop and upstream contract
remain bound to every task. Keep all30 in order; no success-only queue.

If an automatic measurement mask exists, preserve it byte-for-byte as the seed.
Otherwise use an explicitly empty annotation canvas; do not borrow the parent
mask or synthesize app strokes from research points/polygons. Empty starts are
manual annotation from scratch, not a successful automatic mask. This isolated
editor does not implement failed-run rescue in the correction demo.

Only visible facial skin is selected. Exclude hair, beard/moustache, brows, eyes,
lips, mouth interior, objects, clothing and neck. This editor has no correction
or historical brightness controls. No cached protection mask is available in
this cohort: this is full manual measurement annotation, not an override of
the desktop's locked protection policy. No anatomical validity is inferred from
the brush alone. Show the unoverlaid image alongside the measurement overlay.

Save explicit user review as either reviewed selection or unjudgeable, even
when no strokes were needed. Preserve strokes, task-manifest hash, resulting
mask and statistics in a fresh immutable annotation directory. Keep the 1,000
selected-normalized-pixel/valid-ITA guard; invalid selections may be saved as
failures but never become usable records. Zero edits are not approval without
the explicit reviewed-selection action. Revisions remain separate and refer
to the same task; never count them as independent samples. No generated test
annotations may enter the real queue.

No scientific/calibration/training admission is automatic. Check actual support,
condition/score/group coverage and unavailable outcomes before specifying a
subject-disjoint calibration design. Keep each subject's conditions and future
derived records in one allocation. Unknown allocations remain null. This work
does not select a calibration fit, correction target or new tree comparison.
