# Next Table 2 coverage experiment: preparation protocol

28 October 2026. Preparation protocol, not an executed experiment or fitting
authorization inferred from improved masks. The next stage should first measure
whether the current one-distortion-per-source design leaves important recovery
conditions unsupported. Keep all prior negative results and quality gates.

1. Use exactly the eight currently accepted source groups: 22211, 22454, 62331,
   6236, 67583, 75027, 83205 and 84364. No rejected-source reinstatement or source
   choice based on predicted quality. All remain historically exposed development
   sources; different photos do not prove different people.
2. Generate all three fixed Table 2 severities per source as explicitly labeled
   **counterfactual diagnostic probes**, alongside the saved identity controls.
   This does not relabel anyone's MST, alter the proposed MST-conditioned training
   assignment or authorize training all severities as though the paper required it.
   Reuse the saved references and generation masks; retain exact operator order,
   clipping counts and all generation failures. Preserve every existing artifact.
3. Keep the square256 measurement contract and experimental lookup unchanged.
   Compute features from each actual input. No clean-reference substitution or
   broader application-mask statistics in the inference vector.
4. Compare current and the fixed non-skin-veto application candidate separately.
   Record unavailable candidates without fallback; preserve anatomical exclusions.
   Do not tune either policy against these probes. New distortion masks need
   explicit review before any future training admission.
5. First report measurement availability, reference-mask retention, clipping and
   bounded approximate recovery residuals. Fitted oracle scores are capacity
   diagnostics, not learned performance. Use the fixed reference support so that
   dropped input skin cannot shrink the denominator favorably.
6. Optionally replay the **existing** held-source fold predictor on each new probe,
   without fitting or selecting a model. Keep original 16-pair results separate
   from counterfactual probe summaries; no promotion or final accuracy claim.
7. Before any later fit, decide whether added training conditions remain faithful
   to MST-conditioned Table 2 severity and whether a larger reference-screened
   source pool is necessary. A counterfactual diagnostic does not silently change
   the training method. Keep overall improvement and zero clean-control harm as
   separate requirements; no threshold relaxation or post-hoc gate.

This preparation addresses a specific design limitation: only two light and six
medium source-conditioned distortions currently accompany eight controls, with no
dark-source coverage. Counterfactual dark processing is not dark-complexion
coverage. Neither this plan nor an eight-source result completes independent
evaluation, expert MOS, MST validation, face/neck support or Android integration.
