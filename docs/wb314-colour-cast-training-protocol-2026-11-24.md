# One WB314 colour-cast training trial

The current Android test processed a cool-looking portrait and returned identity. The existing WB314 training recipe uses the same red attenuation and blue boost for every synthetic colour condition. This assessment tests wider cast coverage while keeping the frozen expert and manuscript builds fixed.

Reuse the 66 cached, exposed development cases from 11 source portraits. From each cached identity image, add exactly four colour-only variants using linear-light red and blue gains. Weaker cool uses `(0.925, 1.075)`, warm uses `(1.15, 0.85)`, green uses `(0.90, 0.90)`, and magenta uses `(1.10, 1.10)`. Green remains the reference channel. These are whole-image processed-sRGB perturbations with clipping at the representable limit. The target is the analytic inverse with exposure, gamma, and chroma controls set to one. Record clipped inputs. Keep the original masks, model features, renderer and tree settings. Allocate weight `1/5` to each of the five colour-only rows per source, so the original colour-only role retains total weight one. Keep every other row at weight one.

Fit one depth-four tree for each of the 11 existing source-held folds. Exclude every variant of the held source from fitting. Score the candidate and saved source-held WB314 on the same original and newly generated inputs. Seal all held predictions before rendering. Also score the uncorrected inputs against their cached photographic references. Use mean RGB absolute error and mean CIEDE2000 on positive-alpha pixels, and verify exact protected and outside-support preservation for every render.

The candidate must improve both mean errors against the comparator and uncorrected inputs for each of the four new cast conditions. Each cast must improve both errors against input on at least six of 11 held sources. Each original condition must retain or improve both mean errors and must have no increase in cases worse than input in either metric. The number of modified original identity outputs must not increase. Apply a `1e-10` tolerance for floating point comparisons. Report all conditions and failed checks. No feature/setting grid, follow-up refit, or device adoption is part of this assessment. A numerical pass would still need separately planned natural-photo checks before promotion.

Keep the 44 added views and outcomes separate from evidence on new people or natural capture faults. The UT Austin photos inform the problem and stay out of this training and scoring set. The trial uses cached data from the exposed development pool, with no reopening of a closed study or locked data or manifests. Keep photos, individual features, trees and private records local. Publish code and aggregate evidence.
