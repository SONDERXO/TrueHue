## Consequence for the next repair

The intended correction behavior remains useful exposure/colour changes while preserving acceptable photos. A next model repair must justify improved source transfer of those decisions. Simply making leaf outputs more conservative, adding identity rows that already exist, changing MSTbrightness thresholds, or painting larger masks does not address the demonstrated problem by itself. Identity is a review/recipe label unavailable to single-photo inference and cannot be used as a runtime shortcut. No identity-veto model, leaf rewrite, loss/weight/depth/feature sweep or new fit is selected here.

The concrete outcome of this diagnosis is to rule out leaf-target mixing as the mechanism in these nine failures and focus any future proposal on routing transfer. This is not sufficient positive evidence for a specific new training campaign. Keep the failed candidate closed; a later routing proposal needs a distinct inference-time cue or training-design rationale, a prospective specification and source-held assessment before adoption. No extra user review or image collection is needed for this saved-evidence result.
