# Portrait-exposure supervision: source review completed

16 November2026. A task-specific exposure-quality prior is a plausible new learning basis, but no usable pretrained portrait-exposure checkpoint was found in the checked official PIQ23 repository or releases. This review selects no fit and demonstrates no correction improvement.

The official repository was checked at commit4a20fa824c7d082c00277229238b71a78067af3f. Its complete116-entry tree contains one weight-file entry: the zero-byte NTIRE24 submission placeholder. The submission script writes constant scores; it is an example, not a trained model. Releases are empty. The SemHyperIQA source has an empty defaultWeights mapping and points only to generic KonIQ HyperIQA initialization. The README still lists pretrained weights as future work. These findings do not prove the authors have no weights elsewhere.

Public exposure annotations are usable for a narrow metadata assessment:5,116 unique image paths,50scenes, finite scores/standard deviations and ordered confidence intervals for all rows. Of272,196 within-scene unordered image pairs,99,159 have strictly non-overlapping intervals; every scene has at least one. A second exhaustive pair enumeration agrees with the first sorted-interval calculation. These are derived potential ranking targets, not99,159 independent expert comparisons, extra people or confirmed statistical-significance tests. PIQ23 itself discusses dependence between score intervals and uses additional statistical analysis. No fitted quality head, portrait feature or correction output was assessed here.

PIQ23 supplies expert judgments of facial exposure quality, including contrast/dynamic-range considerations. It supplies neither signed EV controls nor aligned corrected targets. Scores are scene-relative; pooling raw JOD as a universal desired brightness would be unjustified. Its paper also explicitly distinguishes judging photographic quality from knowing a person's actual skin reflectance. This preserves TrueHue's photographic-restoration scope and does not establish darker-tone fairness.

This is not a new dataset discovery: the9November source review already recorded PIQ23 as quality evidence. The distinct proposal is to learn an exposure-specific prior from that supervision, rather than use it as a corrected-pair source or cycle generic pretrained IQA checkpoints. Existing mean/quantile/bright-pixel, separate-head/classifier, conditional-prior, generic-ReIQA, neighbour and paired-reference-projection failures remain closed.
