## Compatibility decisions

The native1p5crop bridge is shared at the implementation level, but the prior
PPR automatic records and the new native-manual method are not automatically
equivalent. Human-reviewed masks, preprocessing/colour semantics, seed provenance
and numerical measurement contracts need an explicit compatible path. The
current manual-method identity is preserved, not overwritten or pasted onto old
PPR measurements.

The completed isotonic assessment contains ten different subject-held mappings,
not a single admitted artifact for new PPR input. Do not arbitrarily pick a fold,
average models, rebind a contract hash or fit all30calibration rows during this
readiness step. The observed cool-light weakness remains. A later integration
design must separately specify and assess its mapping/transfer claims.

PPR has no reference MST labels in these records. That does not inherently
prevent generating input-derived MST features from a separately justified
external calibration; it does prevent claiming PPR mapping accuracy from these
records. Never invent labels from source/target colour or insert known reference
tone into inference features. Source and target features must be measured on
their own inputs. No paired delta or target information enters prediction.

The same16feature definitions are retained as a proposed schema, not new evidence
that green/scene features solve the previous failure. No depth/weight/recipe/
feature sweep is reopened. If a bounded photographic-supervision comparison
becomes justified, freeze its exact roles, matched operator/costs, grouped splits,
failure accounting and unchanged joint gates before fitting. Reference-style
acceptance alone cannot supply these requirements or cure wrong-person/detail
failures. The known904case remains a failed pipeline outcome even if its target
style is liked;1188is not silently discarded for a more favorable denominator.
