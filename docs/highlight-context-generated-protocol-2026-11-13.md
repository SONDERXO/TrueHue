# Highlight-context mathematical feasibility protocol

13 November 2026. User chose to continue model research; paper remains paused. This selects one bounded generated-only mathematical assessment, not photo extraction or training.

Rationale: a specular component can supply information different from average skin colour. Test the inverse-intensity chromaticity relationship before designing any actual highlight selector. Retain one correction tree, ITA/MST, traditional single-photo inputs and existing supports. Do not replace the photographic restoration target with physical illumination recovery.

Primary source read: Tan, Nishino and Ikeuchi, *Color constancy through inverse-intensity chromaticity space*, JOSA A 21 (2004), author PDF https://vision.ist.i.kyoto-u.ac.jp/pubs/RTTan_JOSA04.pdf, sections 1–3, especially equation 15. The paper assumes linear sensor response and identifies highlight selection as unresolved. This assessment uses an independently specified ordinary line fit on known generated patches, NOT the published Hough/histogram algorithm or author parity. No literature PDF is saved locally.

History check: targeted search of docs for dichromatic/specular/colour-line terminology found no prior such trial. Read spatial NSS, gray-pixel, source-transfer and consolidated design results. This is neither spatial luminance NSS, gray-pixel selection, eye geometry nor a spectral-bin rescue. Search absence is not proof no historical mention exists.

Frozen construction: three diffuse RGB reflectances (.6,.3,.2), (.3,.45,.2), (.2,.3,.55); two effective illuminants (1,1,1), (245/255,1,1); diffuse weight .2; 33 specular weights uniformly from 0 to .4. Pixel vector = illuminant * (.2*reflectance + specular_weight). Values stay below 1. Use linear and power-encoded exponent 1/2.2 representations; identity, gamma-under exponent 1/.7, gamma-over exponent .7 and red-only gain 245/255. Quantize each final input with round(255*v), then divide by 255. Exactly 48 records, no fit to model targets.

For each supplied patch, regress each chromaticity I_c/sum(I) against inverse total intensity 1/sum(I) using ordinary least squares. Record intercepts and per-channel RMS residual; return unavailable on zero intensity or zero variance. Intercepts are mathematical outputs, not a measured white reference or correction controls. No threshold-selected availability or trust policy.

Checks: unquantized linear identity intercept must reproduce normalized effective illumination within 1e-12 for all six material/illuminant pairs; independent two-endpoint intercepts must agree within 1e-12. A neutral-illumination cool edit and a red-reduced-illumination identity must yield exactly equal RGB8 patch arrays for all three materials in linear representation. That counterexample tests whether estimated total effective colour can be interpreted as the added edit without baseline information; it is not a universal-identifiability requirement or a proof this feature cannot aid a learned predictor.

Report all 48 records, including nonlinear/quantization residuals, without selecting materials, thresholds, linearization variants or a selector after results. No author-performance claim, photographic feasibility or transfer claim. A positive ideal equation check alone does not qualify actual extraction/training; interpret the processing and original-reference gap explicitly. No Hough implementation, photo reads, model predictions/fits, holdout access, runtime changes or user annotation task. All outputs created once in a new directory; existing outputs preserved.
