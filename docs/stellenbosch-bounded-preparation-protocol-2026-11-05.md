## Source-label policy fixed before results

Retain the supplied MST score as a continuous source score within1–10, preserving
raw value/type and exact decimal text. Do not round, bin into ten classes, drop
fractional subjects or insert a reference score as predicted model input.
This is the source-target policy for this development preparation. It is not
an assumption of equal physical/perceptual distances between MST numbers.

For a later separately justified calibration study, the candidate target remains
the supplied decimal score, ITA remains the measured predictor, and evaluation
would use source-score absolute error with subject-balanced, held-subject
reporting and a fitting-subject median baseline. No integer-category accuracy or
thresholds can be claimed from these decimal targets. The existing integer-only
threshold calibrator, runtime MST schema and correction tree are not modified
or fitted now; any later continuous-score adapter requires its own version and
validated scope. No numerical adequacy/acceptance criterion is invented here.
