## Fixed family and solver

Controls in fixed order: [q,red_gain,blue_gain,input_scale,input_offset].
Transform normalized encoded RGB y as
`clip(max(0,input_scale*y+input_offset)**q * [red_gain,1,blue_gain],0,1)`.
Apply supplied, protection-vetoed alpha after transform. Round once for RGB8;
restore zero-alpha pixels exactly. Identity is[1,1,1,1,0]. Existing operators,
target fitter and active three-output artifacts stay unchanged.

One identity-start SciPyTRF linear squared-float-RGB least-squares call, same
ftol/xtol/gtol1e-10 and max_nfev500 as the current fitter. No restarts, smoothing,
regularization, solver choice, loss or bound sweep. Bounds are:

| Control | Lower | Upper | Rationale |
| --- | ---: | ---: | --- |
| q,red_gain,blue_gain | .25 | 4 | Retain existing three-control search limits |
| input_scale | .5 | 2 | Fixed positive engineering envelope containing the exposure inverse scales1/1.05,1/1.08,1/1.10; not a physical prior |
| input_offset | -.3 | .3 | Fixed engineering envelope containing every declared directional-row exposure inverse offset, whose magnitudes are below.252 |

These limits are prospective choices, not inferred from optimized photo targets.
They constrain this feasibility fitter only; no claim that all real corrections
fall within them. An active bound is reported, not expanded to improve a result.

Input and reference can be float RGB[0,1] for noiseless arithmetic fixtures or
RGB8 for quantized probes. Fit only supplied alpha>0, with explicit boolean
protection and exactly0alpha on protected pixels. Do not repair support or
select a favorable intersection. Fixed guard requires each selected input
channel range greater than1/255; smaller ranges stay unavailable. This is a
conservative engineering guard, not a clinical or complexion-quality rule.

Exact input/reference agreement on selected pixels returns neutral without an
optimizer. Otherwise require finite in-bounds controls, convergence, numerical
Jacobian rank5 and float mean-square loss no worse than neutral plus1e-12
arithmetic tolerance. Report singular values and condition number; rank5 is
necessary here, not proof of stable/unique controls or safety. Failures stay
unavailable, without identity substitution. Record all fitted attempts, actual
RGB8 residual, active bounds, pre-power floor and output clipping. A finite
positive transform is not necessarily desirable; it can lift acceptable shadows.

4. One noisy-free known-control case with zero/core/feather/protected support,

The four known controls, and the spatial/quantized controls from the first case,
are source-generation constants, not outcome-selected values. Reference targets
are generated by this same proposed family for the engineering mechanism check;
they are not independent evidence of photographic validity. All generated cases
must remain labelled as generated; no real records or annotation work are used.

Noiseless recovery checks require float-RMSE at most1e-6 and known-control
maximum discrepancy at most1e-3. These are arithmetic feasibility tolerances,
not perceptual or real-model acceptance thresholds. Quantized and directional
cases are descriptive; no parameter-identification claim is based on rounding.
The two degenerate cases must remain unavailable. Identity, exact three-control
nesting, outside/protected preservation, direct-power scalar render/objective
replay and no-overwrite/failure persistence must pass. Add focused tests for
invalid controls/support, convergence/rank failures and frozen solver settings.

Stop without retuning if the noiseless mechanism or engineering checks fail.
Preserve partial evidence. Even if they pass, report condition numbers and
remaining combined/clipping residuals rather than declaring target stability or
automatic colour correction. Main rehearsal counts exclude separate unit-test
fits. No real-photo target comparison, tree fit or rating batch follows without
a separately bounded decision using the observed conditioning and task benefit.
