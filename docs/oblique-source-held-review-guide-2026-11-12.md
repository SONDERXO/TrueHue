# Review the 44 frozen development cases

Double-click `review_oblique_comparison.cmd`. Keep its server window open. This opens the real development comparison, separately from the two-pattern generated preview. You can stop and reopen it without losing saved revisions.

1. Check the viewing setup fields. Enter your OS scale; mark unknown settings as unknown. Use the same display throughout, and record a change if unavoidable.
2. For cases without R, answer whether A and B show a noticeable change in skin brightness, colour, natural appearance, boundaries or protected objects. Choose cannot judge when uncertain. A preferred change can still be noticeable.
3. For cases with photographic reference R, choose which panel is usefully closer to R, or no noticeable difference/both unacceptable/cannot judge. Separately mark the panel with an unwanted artifact. Add a reason for a concern or uncertainty.
4. Use Native 100% to inspect both panels at the cached image's actual size. This is a 256-pixel working image, not the original photograph's full detail. Keep the same inspection context for both panels.
5. Click **Save ratings** regularly. The status must confirm how many cases were saved to disk. You may save partial progress and use **Reload saved ratings**. Finish all 44 cases, save, and confirm **Saved 44/44 ratings to disk** and **All ratings saved**.
6. Click **Download saved JSON**, then tell us you are done. The immutable server revisions are retained in outputs/oblique_source_held_comparison_v1/ratings; the download is a separate copy.

Input/output positions and scores stay concealed during these initial ratings. Do not open private result JSON files first. The photographic reference is a target for this development assessment, not physical skin-colour truth. Ratings are researcher development review, not independent expert MOS. Do not alter masks or infer MST labels during the task. No need to redo any earlier mask or measurement reviews.
