# Review the thirty brighter captures

Double-click `review_brightness_measurements.cmd` in the TrueHue folder. This
opens the new thirty-capture queue; the previous completed queue is separate.

Use **Remove**, **Add skin**, and **Restore initial selection** to select visible
facial skin. Exclude facial hair, head hair, brows, eyes, lips, objects and neck.
Three cases start empty: choose Add skin and paint the visible facial skin.
If the image cannot be judged reliably, use **Save as unjudgeable**.

For every case, click **Save reviewed selection** even if no edits were needed.
The Save controls are above the images. Wait for the Saved message and count to
update before clicking Next. Closing with unsaved edits prompts before discarding
them; reopening restores saved revisions, not unsaved work.

Finish when the counter reads **30/30 reviews saved**. Then tell me it is done so
I can audit the actual exports. These tasks measure skin; they do not change the
correction brightness or train a model. Your earlier thirty reviews need no redo.
