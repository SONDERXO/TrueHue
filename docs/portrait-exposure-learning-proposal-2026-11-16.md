This is a concrete decision for the user before changing the learning scope. Friday20November before noon Manila remains requested; this proposal cannot establish a completion date.

The observed problem is an exposure decision failure: three reviewed candidate inputs receive neutral controls from identity-only leaves. The current control model has not learned a reliable cross-person distinction between exposure that should change and acceptable natural appearance. Adding another raw brightness statistic or changing a held-case threshold does not supply the missing photographic preference supervision.

Proposed additional learning stage: keep the already verified ReIQA encoder frozen, and train ONE small linear quality head using PIQ23's facial-exposure judgments. Train relative rankings within scenes, not pooled absolute JOD. Public scores/intervals can support derived ordering targets; they are not raw independent observer votes or signed EV labels. Label construction and use of uncertainty must be frozen explicitly before training; the source review's interval counts are feasibility evidence only.

Proposed input features: for one input face, measure the learned head's response to two fixed internal exposure probes, minus0.5EV and plus0.5EV, relative to the unchanged input. Append the two relative score changes to the existing314features for ONE control predictor. The probes measure a possible preference direction; the final predictor continues to emit correction controls. No reference photo is available during inference. No external model supplies replacement portrait pixels or a universal target skin brightness. This is a hypothesis about usable supervision, not a demonstrated exposure solution, published-method reproduction or guarantee against bias.

The intended preservation mechanism is to let a portrait-specific learned preference respond differently to acceptable originals and distorted inputs, instead of treating all darker faces as underexposed. It may still learn harmful photographer/device preferences, fail on synthetic probes, or lose relevant information in the frozen encoder. Relative score differences remove additive scene-score offsets but do not solve scene-dependent scale, domain shift or darker-skin qualification. Those limitations must be measured, not assumed away.
