## One concrete candidate: discrete processing footprints

[Wang and Yao, Gamma Correction Parameter Estimation Via Histogram Gap Feature,2024](https://www.jas.shu.edu.cn/EN/10.3969/j.issn.0255-8297.2024.02.010) describes estimating an added gamma operation using empty histogram bins and inverse-transform gap patterns. The publisher abstract reports robustness to JPEG applied BEFORE the transformation, not a blanket claim about post-edit compression. Full PDF equations were not obtained: its PDF link returned the article page. No author implementation/settings or reproduction is claimed. A2018publisher result was identified but full retrieval returned403; it is not used to supply unseen details.

The proposed rationale here is our own discrete-operator observation: round(255*(code/255)**g) can merge input codes and leave specific output codes unreachable. This reflects an applied quantized edit, not a rule that naturally lighter skin should be darkened or that darker skin should be lightened. Channel-specific changes may also distinguish gamma edits from red/blue attenuation. A small fixed descriptor, if justified, would be added as input to the retained tree; it would not directly set controls, add a second predictor or replace ITA/MST.

Unlike the rejected total-response interpretation, this mechanism is tied to an additional operation on an already encoded photo, matching the primary synthetic task. It differs from existing mean/percentile/end-point summaries, local NSS and gray-pixel selection. A scoped report/code search found no prior histogram-gap correction experiment; this is not a claim about every file or every possible method. No closed experiment is reopened.
