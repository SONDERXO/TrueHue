## Scope and readiness

All30 native-manual development cases now have explicit user-reviewed selections
and valid measurements, spanning allten publisher subjects and allthree existing
conditions. Script729 verifies37 saved revisions, exact task/label/group joins,
brush replay, mask hashes and Lab/ITA arithmetic. Allsix latest contact sheets
were viewed. The four missing saves from the first audit are resolved. No new

This supports preparing **one developmental mapping assessment** with the new

## Fixed data and separation

Use the30 latest hash-bound annotations only; keep all37 revisions as evidence.
Revision selection follows the editor's newest annotation-file mtime, with no
ties. No earlier revision may be selected based on more favorable statistics.
Bind each row to source hash, exact decimal publisher score, subject, condition,
input bridge, task manifest, annotation manifest and the shared method identity.
No score is estimated from a photograph or borrowed from a historical predictor.

Specify ten leave-one-subject-out folds, ordered by publisher subject ID. Each
fold fits only the other nine subjects'27 observations and evaluates allthree
conditions of the held subject. Each fitting subject has total weight1, split
equally among its available fitting observations. No held-subject observations,
labels, normalization statistics or descendants enter fitting. The data are
historically exposed development data; these folds are not a new blind test.

If reviews change later, preserve this snapshot and issue a new data version.
Retain unavailable outcomes in every fold denominator; never impute old masks or
substitute a reference MST score as the prediction. No source-group tree-training
allocation is created by these temporary calibration fold roles.

## One fixed assessment candidate

For a subsequent separately recorded execution, use only input-derived ITA to
fit a nonincreasing isotonic least-squares mapping to the exact decimal publisher
MST scores. Weight subjects equally as above. Piecewise-linear interpolation
between fitted knots and endpoint clipping are explicit. No colour-condition
tag, source score, subject ID or reference photograph is an inference feature.
No ITA formula/sign change, Lab-context feature search, threshold/bin invention,
model sweep, hyperparameter tuning or repeated revision repair is included.

Comparator: the median score among the nine fitting subjects, using each subject
once. Record all30 held-subject predictions, clipping/outside-support flags,
absolute errors, equal-subject MAE, per-condition errors, per-subject errors and
within-subject prediction ranges. Report decimal-score errors, not invented
integer-category accuracy. Reference scores cover2.4–9.2; this is not full
official-category support. Baseline improvement alone would not confer validated
calibration or production admission. No all-data deployable fit follows by default.

The intended empirical ITA→MST direction is retained; a poor result must remain
a poor result. In particular, selected masks cannot remove the effect of
illumination and chromatic casts. Do not silently introduce condition-specific
calibrators or reverse the formula to improve observed results.

## After the assessment

Proceed toward correction only if the mapping evidence and separately declared
acceptance requirements justify it. Retain ITA, compatible mapped MST and the
decision-tree final predictor. Correction targets, support/rendering contracts,
clean preservation and subject-grouped correction validation remain separate
requirements; these publisher MST scores are not brightness correction targets.
No promise is made that this calibration will fix the current overly bright demo.

This turn prepares rows and exact fold roles; **zero calibration fits, tree fits
or new mapping predictions are executed**. Final24photos and older locked
allocations remain byte-unread. Existing annotations, audits and model assets are
unchanged. No closed experiment is restarted.
