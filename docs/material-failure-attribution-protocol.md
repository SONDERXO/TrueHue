# Cached material-failure attribution protocol

27 October 2026. Declare before this audit. Use only the frozen17-frame,
51-probe protected-material development experiment. No new source exposure,
inference, model, candidate mask, reference edits, parameter sweep or fitting.
Preserve original user decisions and technical holds.

The question is where known protected pixels enter and survive the existing
pipeline, and whether the material reference seeds already contain them. This
is an explanatory audit of failed development candidates, not an accuracy or
causal evaluation of independent modules.

For each existing user exclusion group and each provisional cosmetic/mark
interior, retain source/frame/variant/reference provenance and pixel counts.
Also analyze unchanged user-labeled facial skin separately. Outside polygons
remains unlabeled. No material truth is invented for qualitative/lighting cases.
The three unavailable probes remain unavailable, not zero-overlap predictions.

Count a declared, disjoint removal funnel: dense skin/nose selection; coarse
face-skin intersection; expanded anatomical exclusion; padded processing bounds;
fixed3D Lab F versus2D chroma C; fixed C2 outlier-neighborhood guard. Funnel order
is accounting only, not attribution of biological or model error causes. Save
category histograms, seed overlap and fixed-distance10/50/90percentiles for each
region. Save F/C/C2 overlaps from existing masks for every available stage.

For the unchanged16798skin/paint references only, report a witness pair if a
paint pixel inside A has smaller chroma distance than an ordinary-skin pixel
inside A, with native coordinates and distances. Such a pair shows that a
single monotone threshold of this frozen chroma distance cannot reject that
paint pixel while retaining that skin pixel. It does not prove impossibility
of paint recognition, apply to all chroma representations, fit a threshold,
or evaluate a hypothetical new mask. Do not use labels to recompute seeds.

Verify all previous artifact/reference/model/source hashes before and after
the audit. Cross-check accounting against saved stage metrics and independently
replay the resulting counts. Visualize fixed funnels on existing images only.
Keep provisional labels separate from original user labels in outputs/reports.
Use findings to specify reference and evaluation requirements for the next
material-specific design; no automatic regeneration, admission or training.
