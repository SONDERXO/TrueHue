# Fixed training-control leaf policy experiment

28 October2026. Separate experiment, not a change to the completed chroma
comparison. Hypothesis: averaging distortion targets with identity targets in
mixed leaves causes avoidable clean-control changes. Use the saved nine-feature
trees with their exact splits; at a leaf containing any **fitting identity
control**, output[1,1,1]. Distortion-only leaves retain their original target mean.
No fitted count ratio, held-case threshold, depth search or new features.

This is a conservative experimental output policy, not ordinary least-squares
leaf regression or an already approved final thesis method. It may withhold
needed correction and cannot protect unseen clean inputs routed into
distortion-only leaves. Identity means the synthetic unchanged target, not
calibrated judgment that every original photograph is correctly exposed.

Freeze all ten original source/duplicate-group folds and20approved pairs. Derive
leaf membership only from18fitting rows per fold, never either held row's label,
reference, target or evaluation metric. Require exact identity targets for each
declared fitting control. The inference export contains only feature tests and
fixed parameter vectors, not lookup by source identity. Keep Lab/ITA/MST and
chroma features, masks, target fits, reference scoring support, exclusions and
accepted concerns unchanged. Save modified portable exports separately; preserve
all original trees and model artifacts. No active model or Android replacement.

Evaluate all20held cases and compare no correction, original9feature tree and
this policy on exactly the same inputs. Report clean/distorted outcomes separately,
every change/no-op and retained harm. Also check whether all fitting controls
remain unchanged, explicitly distinguishing that training property from
held-source quality. Gates remain overall improvement versus no correction
AND zero held clean-control harm. Even a gate pass is exposed-development
evidence, not independent final evaluation or automatic promotion. No further
rule tuning from these outcomes. Software verification must replay splits and
reconstruct outputs independently. This experiment does not resolve clipping,
reference suitability, weak MST, absent dark-group coverage or person separation.
